# CareerOS

CareerOS is an open-source, self-hostable Career Operating System. It helps users discover high-quality opportunities, choose the right resume, manage applications and relationships, and learn from outcomes—while keeping users in control of applying, networking, interviewing, and decisions.

## Status

Phase 0 documentation is complete. Phase 1 implementation begins with the foundation: authentication, multi-tenant user data, master career profiles, resume profiles, encrypted BYOK settings, and the dashboard shell.

## Guiding rule

> Does this reduce repetitive work while increasing interview probability?

If not, it does not belong in CareerOS.
